# Reinforcement learning-based adaptive filter selection for PPG-derived heart rate estimation

This directory is a submission-ready local draft based on the completed run of `monte_carlo_1.ipynb` and the exported files in `paper_outputs/`.

Files:

- `main.tex`: journal-template manuscript with author information omitted from the main document.
- `titlepage.tex`: separate title page containing placeholders for the real authors, affiliations, ORCID iDs, and corresponding-author e-mail.
- `elektr.cls`, `elksty.tex`, `elk-creative.eps`: official Turkish Journal of Electrical Engineering and Computer Sciences template assets downloaded from the journal website.
- `figures/`: PDF versions of the exported experiment figures.
- `supplementary/`: exported tables and `experiment_config.json`.

Before submission:
